# v1 screenshot checklist

Bu klasöre yalnızca gerçek uygulama ekran görüntüleri eklenmelidir. Görüntüleri
çekmeden önce kişisel isim, CV bilgisi, gerçek e-posta adresi, Gmail message ID,
özel notlar ve gerçek başvuru verilerini güvenli demo değerleriyle değiştirin.

Önerilen dosyalar:

- `applications-dashboard.png` — metrikler, filtre ve güvenli demo başvuru listesi
- `application-detail.png` — seçili başvurunun sekmeli detay görünümü
- `new-application.png` — beş adımlı başvuru hazırlama akışı
- `companies.png` — importer ve seçili şirket yönetimi
- `profile.png` — profil/CV alanları; gerçek CV adı veya kişisel veri olmadan

Önerilen çekim ayarları:

- Tarayıcı genişliği yaklaşık 1440 px
- Tutarlı açık veya koyu tema
- Browser bookmark/personal account bilgilerini kadraj dışında bırakma
- OAuth URL, token, credentials path ve yerel dosya yollarını göstermeme
- Gereksiz boşluk bırakmadan ana iş akışını gösterme

Gerçek PNG dosyaları eklenene kadar ana README kırık görsel bağlantısı içermez.
